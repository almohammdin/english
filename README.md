# هرجة | Harjah

منصة تعلم الإنجليزية بأولوية أول ثانوي السعودي.

## ما يعمل

- 12 وحدة وفقا لفهرس Mega Goal 1، طبعة المرجع 2025/1447، ISBN 9781398962477.
- 48 درسا أصليا: قواعد، مفردات، قراءة وكتابة، استماع ومحادثة؛ و4 مراجعات تراكمية.
- اختبار تشخيصي، وتدريب واختبار مستقلان؛ حد اجتياز تمارين الدرس 80% وليس إثباتا لإتقان المقرر.
- نطق المتصفح وتسجيل محلي مؤقت للمقارنة الذاتية، دون درجات نطق مختلقة.
- مراجعة مفردات بجدولة بسيطة 1/3/7 أيام، وليست FSRS.
- مكتبة PDF ونص وصوت في IndexedDB. ملفات PDF للعرض فقط؛ لا يوجد استخراج تلقائي للدروس.
- نتائج وملاحظات محلية مع تصدير واستعادة JSON. ملفات الكتب مستثناة من نسخة النتائج.
- خادم اختياري للمعلم مع مصادقة وحدود طلبات وفحص محتوى. لا يوجد مفتاح خدمة مرفق.

## حالة اكتمال المادة

**هذه نسخة تدريبية مساندة، وليست المقرر الرسمي المكتمل لعام 2026/1448.** الملف المفحوص يحمل 2025/1447 رغم اختلاف عنوان بعض صفحات التحميل. المطلوب قبل الاعتماد:

1. مطابقة طبعة المدرسة وفهرسها لعام 2026 المقصود.
2. مراجعة جميع أهداف الدروس، والأنشطة التمهيدية والمشاريع والنطق.
3. ربط كتاب النشاط بصفحاته ومراجعة إجاباته.
4. ربط التسجيلات الرسمية مع مراعاة حق استخدامها. الصوت الحالي تدريب مولد بالمتصفح.
5. مراجعة تربوية مستقلة للأسئلة المفتوحة والكتابة والمحادثة.
6. اختبار المعلم حيا بعد تهيئة المفتاح. الربط لم يختبر بمزود فعلي في هذه النسخة.

النصوص والتمارين أصلية. لم تنشر صفحات الكتاب أو ملفه أو تسجيلاته في المستودع.
مرجع الفهرس: https://www.mnhaji.com/wp-content/uploads/2025/08/kitab-mega-goal1-1.pdf
المصدر الرسمي: https://www.ien.edu.sa/

## التشغيل

يتطلب الخادم Node.js 22+. شغل `node server.mjs` ثم افتح http://localhost:8787.
يمكن نشر ملفات الواجهة على GitHub Pages. لا يشغل GitHub Pages خادم المعلم.

اضبط متغيرات الخادم للمعلم:

- OPENAI_API_KEY: مفتاح الخدمة، لا يوضع في الواجهة أو المستودع.
- OPENAI_MODEL: نموذج متاح في حسابك يدعم Responses API.
- TUTOR_ACCESS_TOKEN: رمز عشوائي لا يقل عن 24 حرفا.
- ALLOWED_ORIGIN: أصل الواجهة فقط؛ مثال https://almohammdin.github.io دون /english أو شرطة أخيرة.
- PORT: افتراضيا 8787.
- HOST: افتراضيا 127.0.0.1؛ استخدم HTTPS وإدارة وصول مناسبة قبل النشر الخارجي.

من إعدادات الواجهة أدخل رابط /api/tutor ورمز الخادم، ثم وافق على إرسال سياق التعلم. رمز الخادم يحتفظ به في sessionStorage. مفتاح OpenAI يبقى على الخادم. التسجيلات وملفات PDF لا ترسل تلقائيا.

الخادم لتجربة عائلية محدودة. قبل خدمة عدة مستخدمين أضف حسابات وصلاحيات وتحديد طلبات موزع وسياسات بيانات مناسبة للعمر. الحفظ المحلي في الواجهة لمستخدم واحد.
